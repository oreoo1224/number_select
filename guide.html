HOW IT WORKS

번호 생성과 데이터 이용 안내

번호가 만들어지는 방식부터 당첨번호 출처, 내 기록의 저장·삭제 방법까지 안내합니다.

1. 번호는 어떻게 만들어지나요?

1~45 중 서로 다른 숫자 6개를 무작위로 고르고, 작은 수부터 정렬합니다. 포함·제외 번호나 추가 조건을 설정했다면 그 조건에 맞는 조합을 골라 보여 줍니다. 같은 브라우저에 저장된 생성 기록과 중복되는 조합은 피하며, 기록은 최대 1,000개까지 보관할 수 있습니다.

‘오늘의 행운번호’도 무작위 번호 조합입니다. 개인의 운세나 다음 당첨번호를 분석한 결과가 아닙니다.

2. 조건을 선택하면 당첨 확률이 높아지나요?

아닙니다. 로또 6/45에서 서로 다른 6개 번호를 고르는 경우의 수는 8,145,060개입니다. 공정한 추첨을 가정하면 어느 특정 조합이든 1등 당첨 확률은 같습니다.

예를 들어 연속수를 제외하는 조건은 그런 형태의 조합을 만들지 않도록 거르는 기능입니다. 과거에 자주 나온 형태라는 이유만으로 다음 추첨에서 더 유리해지는 것은 아닙니다. 여러 조건을 함께 적용하면 생성할 수 있는 조합의 범위가 줄어듭니다.

3. 당첨번호는 어디에서 가져오나요?

당첨번호는 동행복권 공식 사이트의 로또 6/45 추첨 결과에 사용되는 조회 주소에서 직접 불러옵니다. 사이트의 점검이나 조회 방식 변경에 따라 이용이 제한될 수 있습니다.

페이지를 열 때 최신 회차 조회를 시도합니다. 외부 데이터 갱신이 늦거나 통신이 실패하면 최신 번호를 표시하지 못할 수 있습니다. 보관 자료가 표시되거나 최신 번호 확인 안내가 나오면 공식 결과를 확인하고 직전 회차 번호를 직접 입력해 주세요.

직전 회차와의 중복 조건은 당첨번호 6개를 기준으로 계산하며 보너스 번호는 포함하지 않습니다. 직전 번호를 직접 입력한 경우에는 입력한 6개 번호를 기준으로 합니다.

4. 생성 기록은 어디에 저장되나요?

번호와 설정은 현재 이용 중인 브라우저의 저장 공간에 보관됩니다. 계정에 저장되는 방식이 아니므로 다른 기기나 브라우저로 자동 동기화되지 않습니다. 시크릿 모드나 저장이 제한된 환경에서는 기록이 유지되지 않을 수 있습니다.

기록과 설정을 지우는 방법
결과 화면의 ‘기록 초기화’는 생성 기록과 최근 결과를 비웁니다. 선택 조건과 계산용 저장 정보까지 모두 지우려면 브라우저 설정에서 luckzip.com의 사이트 데이터를 삭제해 주세요.

5. 파일 저장·공유와 당첨 비교는 어떻게 하나요?

결과 화면에서 TXT 파일이나 PNG 이미지로 저장할 수 있으며, 지원되는 브라우저에서는 다른 앱에 공유할 수 있습니다. 내려받은 파일과 공유한 내용은 브라우저의 기록 초기화와 별도로 관리해야 합니다.

‘저장 번호 당첨 확인’은 저장한 조합과 입력·조회한 당첨번호의 숫자 일치 여부를 비교합니다. 실제 복권을 구매했는지나 해당 회차에 구매한 번호인지는 확인하지 않습니다. 최종 결과와 수령 절차는 동행복권 공식 사이트에서 확인해 주세요.

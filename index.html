Number combination tool

번호 조합 생성기

원하는 조건만 골라 1~45 중 6개 번호 조합을 무작위로 생성합니다. 생성 기록과 조건 설정은 이 브라우저에 저장됩니다.

1. 제외 조건 선택

8 / 8개 적용

처음에는 기존 프로그램과 동일하게 8개 조건이 모두 선택되어 있습니다. 체크를 끄면 해당 조건은 생성 과정에서 적용하지 않습니다.

2. 기준 번호

‘기준 번호와 3개 이상 중복 제외’ 조건을 켰을 때만 사용됩니다.

8개 조건이 적용되어 있습니다.

3. 번호 생성

조건을 선택한 뒤 번호 생성을 눌러 시작하세요.

누적 기록 전체와 새로 생성하는 묶음 내부에서 완전히 같은 조합은 만들지 않습니다. 최대 1,000개까지 저장됩니다.

4. 누적 보관함 0 / 1,000

최근 저장 50개 보기

같은 브라우저의 로컬 저장소에 기록됩니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 기록이 이어지지 않으므로 필요한 경우 JSON 백업을 보관해 주세요.

홈 화면에 설치

이 도구는 번호 조합 생성 및 통계적 조건 필터링을 위한 도구이며, 결과를 예측하거나 보장하지 않습니다. 선택 조건은 가능한 조합을 걸러낼 뿐 각 개별 조합의 추첨 확률을 바꾸지 않습니다.
기록과 설정은 서버로 전송하지 않고 사용 중인 브라우저에 저장합니다.
개인정보: 생성 기록과 설정은 사용 중인 브라우저의 로컬 저장소에만 저장됩니다.
